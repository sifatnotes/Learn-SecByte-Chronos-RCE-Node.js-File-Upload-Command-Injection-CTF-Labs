## Learning Path

A practical progression through this collection is:

1. **Start with Chronos Node Probe** to understand the application's Node.js attack surface.
2. **Explore package and exposure reconnaissance** using Package Sleuth and Exposure Time.
3. **Study file handling** with File Shift and File Upload Breakout.
4. **Move into command injection** to understand how unsafe command processing can affect an application.
5. **Study RCE concepts** with Chronos RCE Forge.
6. **Explore payload-related concepts** through Payload Forge.
7. **Practice shell access** using Shellcraft and Shell Drift.
8. **Work through the Base58 challenge** when encoding analysis is relevant.
9. **Finish with the Post-Exploitation Lab** to consolidate the authorized workflow.

## How to Use the Labs

1. Open a lab from the direct-link index.
2. Follow the lab's setup and authorization instructions.
3. Begin with application reconnaissance and information gathering.
4. Identify files, packages, endpoints, inputs, and exposed functionality.
5. Record findings before attempting exploitation.
6. Test file-upload, command-injection, RCE, or payload concepts only against the designated CTF target.
7. If a shell is obtained, document the foothold and post-exploitation findings.
8. Analyze what caused the vulnerability and how it could be mitigated.
9. Reset and repeat the lab to reinforce the methodology.
